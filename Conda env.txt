# Conda Environment Setup for PDF-QA-Chatbot (Ollama Version)

## Quick Setup
1) conda create --name pdf-qa python=3.11
2) conda activate pdf-qa
3) pip install -r requirements.txt

## Individual Package Installation (if needed)
3) pip install langchain==0.1.0
4) pip install langchain-community==0.0.10
5) pip install langchain-ollama==0.1.0
6) pip install streamlit==1.29.0
7) pip install pypdf==3.17.4
8) pip install sentence-transformers==2.2.2
9) pip install chromadb==0.4.22
10) pip install python-dotenv==1.0.0
11) pip install requests==2.31.0

## Ollama Setup
- Download and install Ollama from: https://ollama.ai/
- Pull a model: ollama pull llama3.2
- Start Ollama server: ollama serve

## Note
This version uses Ollama for local AI inference - no API keys required!
All credentials from the old WatsonX version have been removed for security.
